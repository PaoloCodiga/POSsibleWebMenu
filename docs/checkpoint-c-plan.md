# Checkpoint C delivery record

Checkpoint C is complete in release 19.0.1.0.0.

- **C1** delivered the Website Builder option and OWL configuration dialog.
- **C2** delivered atomic canonical `data-*` Apply, one Builder history step,
  Undo/Redo, and live preview refresh.
- **C3** certified the complete clean-install Chrome workflow: insert,
  configure, apply, live render, undo, redo, save, and public reload.

No reusable persistent configuration model was introduced. Configuration stays
with each Website snippet and uses Odoo Builder history.
