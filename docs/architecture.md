# Architecture

The public Interaction normalizes allowlisted snippet data and calls the readonly JSON-RPC renderer. Trusted server-side QWeb output is inserted exclusively inside `.o_possible_web_menu_generated`.

The Website Builder plugin removes runtime-only output and state from Odoo 19's detached save clone. Saved markup retains structural snippets, headings, subtitles, static container, and canonical configuration only. A duplicated snippet retains configuration but starts an independent Interaction and fresh render.
